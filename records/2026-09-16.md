## 二、训练与评估：参数什么时候会改变？

训练阶段：

```python
model.train()

logits = model(images)
loss = loss_fn(logits, labels)

optimizer.zero_grad()
loss.backward()
optimizer.step()
```

`optimizer.step()` 会修改同一个 `model` 对象内部的权重和偏置。

评估阶段：

```python
model.eval()

with torch.no_grad():
    logits = model(images)
```

评估只有前向计算，没有 `backward()` 和 `step()`，因此参数不更新。

将模型传入函数：

```python
validation_loss, validation_accuracy = evaluate(
    model,
    validation_dataloader,
    loss_fn,
    device
)
```

传入的是同一个模型对象，不是重新创建或复制一个模型。`evaluate()` 使用的就是刚刚训练后的参数。

一次 Fashion-MNIST MLP 评估练习得到：

```text
第1轮：测试损失=0.4460，测试准确率=84.00%
第2轮：测试损失=0.4409，测试准确率=83.82%
第3轮：测试损失=0.3812，测试准确率=86.00%
```

准确率不一定每轮严格递增，损失与准确率观察的是不同方面。

## 三、保存和加载模型参数

保存：

```python
torch.save(model.state_dict(), model_path)
```

`state_dict()` 保存模型中登记的参数，例如：

```text
layer1.weight
layer1.bias
layer2.weight
layer2.bias
```

ReLU、Flatten 和 MaxPool2d 没有可训练参数，所以不会提供对应的 weight。

路径代码：

```python
model_folder = Path(__file__).resolve().parent.parent / "models"
model_folder.mkdir(exist_ok=True)
```

- 第一行只构造路径对象，不要求目标文件夹已经存在。
- 第二行才创建目录。
- `exist_ok=True` 表示目录已存在时不报错，也不会创建第二个同名目录。

加载参数：

```python
model = ImageMLP().to(device)

model.load_state_dict(
    torch.load(
        model_path,
        map_location=device,
        weights_only=True
    )
)
```

过程是：先按原结构创建一个随机参数模型，再用保存的参数替换随机参数。模型结构必须与保存时一致。

分成两句或嵌套写法效果相同：

```python
saved_parameters = torch.load(...)
model.load_state_dict(saved_parameters)
```

```python
model.load_state_dict(torch.load(...))
```

分开写更方便打印参数名称和排错。

## 四、取批次、标签编号与预测编号

只取一批：

```python
images, labels = next(iter(dataloader))
```

- `iter(dataloader)` 创建迭代器。
- `next(...)` 取一批。
- 适合检查形状、显示图片或快速测试模型。

遍历全部批次：

```python
for images, labels in dataloader:
    ...
```

for 循环会在内部不断调用 next，直到所有批次结束。训练需要使用全部数据，因此使用 for。

标签张量存放的是类别编号：

```text
tensor([9, 2, 1, 1, 6, 1, 4, 6])
```

类别名称单独保存在：

```python
dataset.classes
```

编号转名称：

```python
correct_name = dataset.classes[labels[index].item()]
```

模型预测编号：

```python
predicted_classes = logits.argmax(dim=1).cpu()
```

- logits 形状为 `[N, 10]`。
- `argmax(dim=1)` 在每张图片的十个类别分数中找最大值的位置。
- 结果是 `[N]`，每个元素是预测类别编号。
- `.cpu()` 将结果从 GPU 移回 CPU，便于后续显示和处理。

## 五、卷积：局部区域、权重和特征图

卷积核是一个小的权重表，例如：

```text
-1   0   1
-1   0   1
-1   0   1
```

它盖住图片中的一个 `3×3` 区域，将对应位置逐个相乘后求和，得到输出特征图中的一个数。随后卷积核向右、向下移动，重复计算，最终形成整张特征图。

卷积核不会把原图中框外的内容删除。框外像素只是在当前位置暂时不参与计算，等卷积核移动过去时再使用。

特征图可以类比为特征强度的地理热力图：

```text
数值较大 → 当前位置强烈出现卷积核寻找的特征
数值接近0 → 当前位置没有明显出现该特征
```

不同卷积核产生不同专题地图，可能分别响应不同方向的边缘、纹理或局部形状。真实卷积核的权重不是人工固定，而是通过反向传播训练得到。

## 六、Conv2d 参数和形状

```python
conv = nn.Conv2d(
    in_channels=1,
    out_channels=4,
    kernel_size=3,
    padding=1
)
```

- `in_channels=1`：输入是一通道灰度图片。
- `out_channels=4`：使用四个卷积核，产生四张输出特征图。
- `kernel_size=3`：每个通道上的局部窗口是 `3×3`。
- `padding=1`：外围补一圈 0，使长宽保持不变。

形状变化：

```text
[8, 1, 28, 28] → [8, 4, 28, 28]
```

卷积权重形状：

```text
[4, 1, 3, 3]
```

它表示四个输出卷积核、一个输入通道、每个通道一组 `3×3` 权重。

`nn.Conv2d` 是类，`nn.Conv2d(...)` 创建对象，变量 `conv` 保存对象。由于它继承 `nn.Module` 并实现调用机制，所以可以写：

```python
feature_maps = conv(images)
```

这会经过 Module 的调用流程并执行卷积层的 `forward()`。

## 七、ReLU 和 MaxPool2d

ReLU：

```python
activated_maps = relu(feature_maps)
```

将负值变为 0，正值保留，形状不变。

最大池化：

```python
pool = nn.MaxPool2d(
    kernel_size=2,
    stride=2
)
```

在每个 `2×2` 区域中保留最大值，每次移动两格：

```text
[8, 4, 28, 28] → [8, 4, 14, 14]
```

池化不改变图片数量和通道数量，只缩小最后两个长宽维度。它没有可训练权重，作用是减少计算量、保留明显响应，并降低模型对小幅位置变化的敏感度。

池化层并不知道数据在语义上叫“特征图”。调用：

```python
pooled_maps = pool(activated_maps)
```

决定了它处理的是 activated_maps。MaxPool2d 按 `[N, C, H, W]` 约定，只在最后两个维度上移动。

## 八、单层 CNN 与完整形状变化

单层 Fashion-MNIST CNN：

```text
[N, 1, 28, 28]
→ Conv2d
[N, 4, 28, 28]
→ ReLU
[N, 4, 28, 28]
→ MaxPool2d
[N, 4, 14, 14]
→ Flatten
[N, 784]
→ Linear
[N, 10]
```

CNN 与之前 MLP 的外壳相同，仍然继承 `nn.Module` 并定义 `forward()`。主要区别是：

```text
MLP：先 Flatten，较早丢失二维位置结构
CNN：先 Conv2d 提取局部空间特征，再 Flatten 分类
```

训练循环不因模型内部换成卷积而改变：

```python
logits = model(images)
loss = loss_fn(logits, labels)

optimizer.zero_grad()
loss.backward()
optimizer.step()
```

优化器会自动找到并更新模型登记的卷积权重、卷积偏置和 Linear 参数。

## 十、两层 CNN：后一层怎样接收多张特征图

两层模型形状：

```text
[8, 1, 28, 28]
→ Conv2d(1, 8)
[8, 8, 28, 28]
→ Pool
[8, 8, 14, 14]
→ Conv2d(8, 16)
[8, 16, 14, 14]
→ Pool
[8, 16, 7, 7]
→ Flatten
[8, 784]
→ Linear
[8, 10]
```

第二层权重形状：

```text
[16, 8, 3, 3]
```

表示产生十六张输出特征图；每张输出都会综合前一层全部八张输入特征图，每个输入通道对应一组 `3×3` 权重。

一次两层 CNN 训练结果：

```text
第1轮：训练准确率77.11%，测试准确率81.16%
第2轮：训练准确率85.52%，测试准确率85.23%
第3轮：训练准确率87.32%，测试准确率85.01%
```

第三轮训练准确率继续上升，测试准确率略微下降，可能是随机波动，也可能是轻微过拟合。模型更深不代表短时间训练后一定更准。

## 十二、Normalize：调整像素数值范围

```python
transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize(
        mean=(0.5, 0.5, 0.5),
        std=(0.5, 0.5, 0.5)
    )
])
```

`Compose` 按顺序执行多个转换。ToTensor 将这里的像素缩放到 `0～1`，Normalize 对 RGB 三个通道分别执行：

```text
标准化数值 = (原数值 − mean) ÷ std
```

使用 mean=0.5、std=0.5 时：

```text
0   → -1
0.5 →  0
1   →  1
```

实际观察：

```text
处理前范围：0.0 到 1.0
处理后范围：-1.0 到 1.0
```

索引：

```python
original_image[:, 0, 0]
```

表示取左上角像素的全部 RGB 通道。冒号表示该维度全部保留。

标准化后的图片用于显示时需要还原：

```python
display_image = image * 0.5 + 0.5
```

## 十三、数据增强：让模型学习稳定特征

训练转换：

```python
transforms.RandomCrop(32, padding=4)
transforms.RandomHorizontalFlip(p=0.5)
```

- RandomCrop：先将 32×32 图片外围补四格，再随机裁回 32×32，模拟轻微位置变化。
- RandomHorizontalFlip：每次有 50% 概率左右翻转。

同一个 `dataset[0]` 每次读取都可能得到不同增强版本，但标签不变，数据集长度仍为 50000。数据增强不会把变化后的图片保存成许多新文件。

目的不是改变答案，而是在不改变类别的前提下增加输入多样性，减少模型死记物体的固定位置和方向。

要区分：这里是数据增强 Data Augmentation，不是强化学习 Reinforcement Learning。

训练集可以随机增强；验证集和测试集不能随机变化，否则每次评估的试题不同，结果不便比较。

## 十四、nn.Sequential 与 CIFAR-10 CNN

`nn.Sequential` 将按顺序执行的层打包：

```python
self.features = nn.Sequential(
    nn.Conv2d(3, 32, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(2, 2),
    nn.Conv2d(32, 64, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(2, 2)
)
```

形状变化：

```text
[N, 3, 32, 32]
→ [N, 32, 32, 32]
→ [N, 32, 16, 16]
→ [N, 64, 16, 16]
→ [N, 64, 8, 8]
```

分类器：

```python
self.classifier = nn.Sequential(
    nn.Flatten(),
    nn.Linear(64 * 8 * 8, 128),
    nn.ReLU(),
    nn.Linear(128, 10)
)
```

形状变化：

```text
[N, 64, 8, 8]
→ [N, 4096]
→ [N, 128]
→ [N, 10]
```

因此 forward 可以简化成：

```python
def forward(self, x):
    x = self.features(x)
    logits = self.classifier(x)
    return logits
```

Sequential 适合直线式数据流；有分支、跳跃连接或多个输入时，仍需在 forward 中手动组织。

## 十五、训练集、验证集和测试集

规范划分：

```text
训练集：45000张，更新模型参数
验证集： 5000张，每轮检查并选择最佳模型
测试集：10000张，模型确定后最终评价一次
```

将官方 50000 张训练图片随机划分：

```python
generator = torch.Generator().manual_seed(42)

random_indices = torch.randperm(
    len(train_source),
    generator=generator
)
```

- `randperm(50000)` 生成 `0～49999` 每个编号恰好一次的随机排列。
- `manual_seed(42)` 固定本次划分，方便复现实验。
- `generator=generator` 左侧是函数参数名，右侧是创建好的变量。
- 使用局部 Generator 只控制这次划分，不必改变程序中所有随机操作。

切分：

```python
train_indices = random_indices[:45000]
validation_indices = random_indices[45000:]
```

Subset：

```python
train_dataset = Subset(train_source, train_indices)
```

Subset 只保存原 Dataset 和所选编号，不复制图片文件。

训练 DataLoader 使用 `shuffle=True`，每轮重新组合批次；验证和测试使用 `shuffle=False`，保持评估顺序稳定。随机划分决定哪些图片属于哪个集合，DataLoader 的 shuffle 决定一个集合内部每轮的读取顺序，两者不是一回事。

## 十六、CIFAR-10 规范训练文件

完整文件将已有知识组合起来：

```text
训练集更新参数
→ 验证集检查
→ 验证准确率创新高时保存参数
→ 重复5轮
→ 加载最佳参数
→ 测试集最终评价一次
```

评估函数：

```python
def evaluate(model, dataloader, loss_fn, device):
    ...
    return average_loss, accuracy
```

Python 不强制声明参数类型，也可以添加可选类型提示：

```python
def evaluate(
    model: nn.Module,
    dataloader: DataLoader,
    loss_fn: nn.Module,
    device: torch.device
) -> tuple[float, float]:
```

优化器：

```python
optimizer = torch.optim.Adam(
    model.parameters(),
    lr=0.001
)
```

Adam 会根据参数的历史梯度自适应调整更新幅度，后续再单独深入比较它与 SGD。

训练轮数和最佳成绩：

```python
best_validation_accuracy = 0.0
epochs = 5
```

每轮处理全部 45000 张训练图片。验证准确率超过历史最好值时保存：

```python
if validation_accuracy > best_validation_accuracy:
    best_validation_accuracy = validation_accuracy
    torch.save(model.state_dict(), best_model_path)
```

统计当前批次的实际大小：

```python
batch_size = len(labels)
```

不能始终使用 DataLoader 配置的 64，因为 45000 除以 64 有余数，最后一批只有 8 张。使用实际批次大小才能正确累计损失和样本总数。

完整训练文件已写好，并已生成 `best_cifar_cnn.pth` 检查点；本次对话没有保留五轮完整控制台输出，因此本记录不写未经确认的最终 CIFAR-10 准确率。
