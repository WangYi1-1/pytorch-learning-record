## 一、完整训练流程重新串联

当前 CIFAR-10 项目的主线是：

```text
准备数据
→ DataLoader 分批读取
→ CNN 提取图像特征
→ Linear 生成十个类别分数
→ CrossEntropyLoss 计算损失
→ backward 计算梯度
→ optimizer.step 更新参数
→ 验证集选择最佳模型
→ 测试集进行最终评价
```

### 数据形状

一张 CIFAR-10 图片：

```text
[3, 32, 32]
```

一批 64 张图片：

```text
images：[64, 3, 32, 32]
labels：[64]
```

`labels` 中保存的是每张图片的正确类别编号，而不是类别名称。

### CNN 中的形状变化

```text
[64, 3, 32, 32]
→ Conv2d
[64, 32, 32, 32]
→ MaxPool2d
[64, 32, 16, 16]
→ Conv2d
[64, 64, 16, 16]
→ MaxPool2d
[64, 64, 8, 8]
→ Flatten
[64, 4096]
→ Linear
[64, 128]
→ Linear
[64, 10]
```

最后的 `[64, 10]` 表示：64 张图片，每张图片有十个类别分数。

### 训练的核心步骤

```python
logits = model(images)
loss = loss_fn(logits, labels)

optimizer.zero_grad()
loss.backward()
optimizer.step()
```

- `model(images)`：使用当前参数进行预测。
- `loss_fn(...)`：比较预测分数和正确类别。
- `zero_grad()`：清除上一批累积的梯度。
- `backward()`：计算当前损失对每个参数的导数。
- `step()`：根据梯度更新权重和偏置。

梯度不是“当前批次与上一批次的变化量”，而是当前这次计算中，损失对各个参数的导数。

训练集负责更新参数，验证集负责选择最佳参数，测试集只在最后进行最终评价：

```text
训练集 = 平时练习
验证集 = 模拟考试
测试集 = 最终考试
```

## 二、重新理解 Linear

全连接层的权重和偏置，就是 `nn.Linear` 内部需要训练的参数。

例如：

```python
layer = nn.Linear(3, 2)
```

表示将三个输入特征组合成两个输出特征：

```text
输出1 = w11×x1 + w12×x2 + w13×x3 + b1
输出2 = w21×x1 + w22×x2 + w23×x3 + b2
```

固定规则：

```text
Linear 的 weight 形状 = [输出特征数, 输入特征数]
```

因此：

```text
nn.Linear(4096, 128)
weight：[128, 4096]
bias：[128]
```

这里不是“把很多参数算成更少的参数”，而是：

```text
把每张图片的 4096 个输入特征
组合成 128 个新的、更综合的输出特征
```

随后：

```python
nn.Linear(128, 10)
```

再把 128 个高级特征组合成十个类别分数。

可以概括为：

```text
卷积层：寻找边缘、纹理、局部形状
Flatten：将特征图展开
第一个 Linear：综合大量局部特征
最后一个 Linear：生成各类别的分数
```

## 三、test31 的目标

`test30` 主要回答：

```text
模型整体准确率是多少？
```

`test31` 继续回答：

```text
每个类别分别有多准？
哪些类别容易互相混淆？
模型具体预测错了哪些图片？
```

它只加载已经训练好的最佳参数并进行预测，不会重新训练模型。

## 四、为统计结果准备容器

```python
class_count = len(test_dataset.classes)
class_correct = torch.zeros(class_count, dtype=torch.long)
class_total = torch.zeros(class_count, dtype=torch.long)
```

CIFAR-10 有十个类别，因此两个张量的形状都是 `[10]`。

- `class_correct`：记录每个类别预测正确了多少张。
- `class_total`：记录每个类别一共遇到了多少张。

例如：

```text
class_correct[3] = 476
class_total[3] = 1000
```

表示 1000 张猫中，有 476 张预测正确，猫的准确率是 47.6%。

混淆矩阵：

```python
confusion_matrix = torch.zeros(
    class_count,
    class_count,
    dtype=torch.long
)
```

它的形状是 `[10, 10]`：

```text
行 = 正确类别
列 = 模型预测类别
```

对角线位置表示预测正确，非对角线位置表示错误类别之间的混淆。

```python
mistakes = []
```

普通 Python 列表 `mistakes` 用来保存少量错误图片、正确类别和预测类别，最后进行可视化。

## 五、按批次预测，再逐张统计

```python
with torch.no_grad():
    for images, labels in test_dataloader:
        images = images.to(device)
        labels = labels.to(device)

        logits = model(images)
        predictions = logits.argmax(dim=1)
```

- `torch.no_grad()`：预测时不记录梯度，减少显存和计算量。
- 外层 `for`：一批一批读取测试数据。
- `logits`：形状是 `[batch, 10]`。
- `argmax(dim=1)`：从每张图片的十个分数中选择最高分对应的类别编号。

随后将图片、正确标签和预测结果移回 CPU：

```python
cpu_images = images.cpu()
cpu_labels = labels.cpu()
cpu_predictions = predictions.cpu()
```

这样便于使用 Python 循环统计和 Matplotlib 显示图片。

内层循环逐张处理：

```python
for index in range(len(cpu_labels)):
    correct_label = cpu_labels[index].item()
    predicted_label = cpu_predictions[index].item()
```

`.item()` 将单个数的 Tensor 转成普通 Python 整数。

登记统计结果：

```python
class_total[correct_label] += 1
confusion_matrix[correct_label, predicted_label] += 1
```

如果正确答案是猫（3），预测结果是狗（5），就相当于：

```python
class_total[3] += 1
confusion_matrix[3, 5] += 1
```

正确时增加对应类别的正确数量：

```python
if correct_label == predicted_label:
    class_correct[correct_label] += 1
```

预测错误时，最多保存前八张错误图片：

```python
elif len(mistakes) < 8:
    mistakes.append((
        cpu_images[index],
        correct_label,
        predicted_label
    ))
```

即使已经保存了八张错误图片，程序仍会继续统计完整测试集，只是不再保存更多图片。

## 六、分类统计与整体统计

前面得到的是按类别分别保存的计数：

```text
class_correct：[十个类别各自的正确数量]
class_total：[十个类别各自的总数量]
```

将十个位置相加，得到整个测试集的总数：

```python
total_correct = class_correct.sum().item()
total_count = class_total.sum().item()
overall_accuracy = total_correct / total_count
```

因此，逐张计数和最后求和并不重复：

```text
逐张计数 → 得到每个类别的数据
全部求和 → 得到整个测试集的数据
```

## 七、输出每个类别的准确率

```python
for class_index, class_name in enumerate(test_dataset.classes):
    accuracy = (
        class_correct[class_index].item()
        / class_total[class_index].item()
    )
```

`enumerate()` 同时提供类别编号和类别名称：

```text
0, airplane
1, automobile
2, bird
……
9, truck
```

输出格式：

```python
print(f"{class_name:>10s}：{accuracy * 100:6.2f}%")
```

- `:>10s`：字符串占十个字符并靠右对齐。
- `:6.2f`：数字占六个字符并保留两位小数。

这些格式只改变显示效果，不改变数据。

## 八、显示错误样本

创建两行四列的八个小图区：

```python
figure, axes = plt.subplots(2, 4, figsize=(12, 6))
```

将八个图区和八条错误记录一一配对：

```python
for axis, (image, correct_label, predicted_label) in zip(
    axes.flat,
    mistakes
):
```

- `axes.flat`：按顺序遍历八个小图区。
- `zip()`：将一个图区与一条错误记录配对。
- `(image, correct_label, predicted_label)`：将错误记录中的三个成员拆开。

撤销标准化：

```python
display_image = image * 0.5 + 0.5
```

将 PyTorch 的 `[C, H, W]` 调整成 Matplotlib 需要的 `[H, W, C]`：

```python
display_image = display_image.permute(1, 2, 0)
```

显示图片并标出正确答案与预测答案：

```python
axis.imshow(display_image)
axis.set_title(
    f"True: {test_dataset.classes[correct_label]}\n"
    f"Predicted: {test_dataset.classes[predicted_label]}"
)
axis.axis("off")
```

最后：

```python
figure.suptitle("Misclassified CIFAR-10 Images")
figure.tight_layout()
plt.show()
```

- `suptitle()`：设置整张大图的总标题。
- `tight_layout()`：自动调整各个图区的间距。
- `show()`：打开图片窗口。

## 九、本次实际分析结果

使用 `test30` 保存的最佳模型参数进行测试：

```text
整体测试准确率：69.33%
```

每个类别：

```text
  airplane：73.90%
automobile：75.30%
      bird：53.30%
       cat：47.60%
      deer：61.00%
       dog：60.40%
      frog：80.90%
     horse：76.60%
      ship：86.80%
     truck：77.50%
```

当前模型最擅长识别 `ship`，最不擅长识别 `cat`。混淆矩阵显示猫和狗之间有比较明显的互相误判。

这说明只看 69.33% 的整体准确率是不够的。分类别准确率、混淆矩阵和错误图片可以帮助判断模型下一步应该改进什么。
